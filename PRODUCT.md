# Print ordering

## Register

product

## Users

Small businesses and event organisers need to price and proof custom print work with minimal back-and-forth. Print staff need to see why a job is waiting and retrieve exactly the artwork the customer approved.

## Product purpose

One storefront handles six print divisions with the same configurable product model. The first working journey is a three-runner race order. A second reference journey is 100 identical logo stickers. Each proves that quoted prices, approved artwork, and staff files agree.

## Design direction

The assignment calls for a boutique-industrial feel. Use a strong action colour, a neutral base, geometric headings, and legible specifications. Give each product family equal weight in navigation. Show proof artwork prominently during approval and expose payment, proof, and file readiness independently in the staff interface.

## Accessibility

Support keyboard and touch use, labelled controls, reduced motion, and stable layouts from 360 px to 1440 px. Put validation at the field or row it applies to. Give prices, errors, and status updates text labels.
